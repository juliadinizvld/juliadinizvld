### [Sistema de Clínica Veterinária | *Veterinary Clinic System*](https://github.com/juliadinizvld/projeto_lpoo) 
 
Este sistema foi desenvolvido para o gerenciamento de clínicas veterinárias, oferecendo uma interface gráfica para o cadastro e atualização de dados de pets, tutores, funcionários e produtos, além de funcionalidades para agendamento de consultas, procedimentos e processamento de pagamentos.
**Tecnologias Utilizadas** 
- **Java**: Linguagem de programação principal (Orientada a objeto).  
- **Swing**: Para criação das interfaces gráficas.  
- **MySQL**: Para gerenciamento do banco de dados.  
- **API Mercado Pago**: Para processamento de pagamentos.
O sistema oferece funcionalidades de **cadastro** (de pets, tutores, funcionários, produtos), **consultas e visualizações** (de dados de pets, tutores, funcionários, produtos e agendamentos), **atualizações** (de registros existentes) e **agendamentos** (de consultas e procedimentos, processamento de pagamentos). Ele também integra a API do Mercado Pago para o processamento de pagamentos.

*This system was developed for the management of veterinary clinics, offering a graphical interface for registering and updating data for pets, owners, employees, and products, as well as functionalities for scheduling appointments, procedures, and processing payments.*  
***Technologies Used***  
*- **Java**: Primary programming language (Object-Oriented).*  
*- **Swing**: For creating graphical user interfaces.*  
*- **MySQL**: For database management.*
*- **Mercado Pago API**: For payment processing.*
*The system offers functionalities for **registration** (of pets, owners, employees, products), **consultations and views** (of pet, owner, employee, product, and appointment data), **updates** (of existing records), and **scheduling** (appointments and procedures, payment processing). It also integrates the Mercado Pago API for payment processing.*

### [Análise e Classificação de Dados Utilizando Técnicas de Machine Learning | *Data Analysis and Classification Using Machine Learning Techniques*](https://github.com/juliadinizvld/projeto_IA)

Este projeto tem como objetivo a análise e classificação de diferentes tipos de feijão seco utilizando técnicas de Machine Learning, com base no Dry Bean Dataset. O conjunto de dados contém informações sobre características físicas dos feijões, como área, perímetro, comprimento dos eixos, entre outros atributos.
O objetivo principal é prever a classe do feijão (dentre 7 tipos) a partir dessas características. Foram aplicados diferentes modelos de Machine Learning para identificar a técnica mais eficaz para essa tarefa de classificação. O projeto envolveu a análise comparativa de várias abordagens, com foco na escolha do modelo que entregasse o melhor desempenho em termos de precisão e equilíbrio entre as classes.

*This project aims to analyze and classify different types of dry beans using machine learning techniques, based on the Dry Bean Dataset. The dataset contains information on the physical characteristics of the beans, such as area, perimeter, axis length, and other attributes.*
*The main goal is to predict the class of the bean (out of 7 types) based on these characteristics. Various machine learning models were applied to identify the most effective technique for this classification task. The project involved a comparative analysis of several approaches, focusing on choosing the model that delivered the best performance in terms of accuracy and class balance.*

### [Sistema Petsitter | *Petsitter System*](https://github.com/juliadinizvld/devweb2)

Este projeto foi desenvolvido na disciplina de **Desenvolvimento Web 2**, com o objetivo de criar uma aplicação web dinâmica utilizando a arquitetura **MVC**. O sistema permite realizar operações de **CRUD** sobre entidades, sendo implementado com **Python** e o framework **Django** no backend, e **SQLite** para armazenamento de dados. A aplicação incorpora práticas avançadas como **Microsserviços**, **Publish-Subscribe** e **Serverless**, garantindo escalabilidade e flexibilidade. A implantação foi realizada na **AWS**, utilizando **Cloud9** para desenvolvimento e **EC2** para execução em ambiente de produção.

*This project was developed in the **Web Development 2** course, with the goal of creating a dynamic web application using the **MVC** architecture. The system allows performing **CRUD** operations on entities, implemented with **Python** and the **Django** framework on the backend, and **SQLite** for data storage. The application incorporates advanced practices such as **Microservices**, **Publish-Subscribe**, and **Serverless**, ensuring scalability and flexibility. Deployment was done on **AWS**, using **Cloud9** for development and **EC2** for production environment execution.* <br>
